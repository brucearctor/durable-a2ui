Act I · The Problem

The "90% Agent Demo Trap"

1. Fragile Memory

In-Process State Dies

Standard agent loops store conversation history, cart state, and tool results in RAM. One container deploy or OOM kill wipes the entire session.

2. Text-Only Walls

Markdown Is Not an App

Streaming raw markdown forces users to read walls of text instead of interacting with structured cards, progress bars, and approval buttons.

3. Siloed Agents

Bespoke REST Glue

Without a standard wire protocol, every specialist agent speaks a custom JSON format—and a single timeout breaks the entire multi-agent chain.

💡 The Core Thesis

ADK gives your agent a brain. A2A gives it colleagues. A2UI gives it a face. Temporal gives it a spine.

Declarative Surfaces + Durable Streams

// 1. Send structure ONCE when workflow starts (pkg/a2ui/a2ui.go)
_ = ui.Publish(a2ui.CreateSurface("order-main", false))
_ = ui.Publish(a2ui.UpdateComponents("order-main", []map[string]any{
  {"id": "root", "component": "Column", "children": []string{"hdr", "prog"}},
  {"id": "hdr", "component": "Text", "text": a2ui.Path("/order/status_label")},
}))

// 2. Push lightweight @path JSON Pointer deltas per stage
_ = ui.Publish(a2ui.UpdateDataModel("order-main", "/order", map[string]any{
  "status":       "preparing",
  "status_label": "👨‍🍳 Preparing Your Order",
  "progress":     50,
}))

🌊 How workflowstreams Works

  • Durable Topic Log: Every ui.Publish(msg) is recorded deterministically in the Temporal workflow execution.
  • Zero-Loss Reconnect: Browser SSE passes Last-Event-ID; sc.Subscribe(ctx, FromOffset) resumes from the exact offset.
  • Late-Joining Devices: Scan the QR code halfway through an order—your phone replays messages #0..#N in milliseconds and renders the live surface.
  • Bidirectional Signals: Clicking an A2UI Button posts a Temporal Signal right back into workflow.Selector.

  Name: "add_to_cart",

// 3. Remote A2A call wrapped as a durable Temporal Activity
a2aRestTool, _ := googleadk.ActivityAsTool(A2AFindRestaurantsActivity,
  googleadk.ActivityToolOptions{Name: "a2a_find_restaurants", ActivityOptions: actOpts},
)

⚡ Why This Architecture Wins

  • Deterministic Replay: Every Gemini LLM call runs through googleadk.InvokeModel Activity. On worker crash recovery, Temporal replays recorded LLM responses without re-billing tokens.
  • Zero-Hop State Tools: get_menu, add_to_cart, confirm_order, and send_a2ui_json_to_client run in-workflow in microseconds.
  • Infinite Sessions: googleadk.ExportSession and ImportSession snapshot ADK memory across ContinueAsNew boundaries.

Wrap-Up & Q&A

4 Rules for Production AI Agents in 2026

✅ Architectural Takeaways

  • 1. Separate Structure from State (A2UI v1.0): Send component trees once; stream lightweight @path JSON Pointer data-model deltas.
  • 2. Standardize Agent Boundaries (A2A v2.8): Discover specialist agents via /.well-known/agent-card.json and communicate over JSON-RPC 2.0.
  • 3. Enforce Guardrails in Code, Not Prompts: Check safety invariants and human approval gates deterministically in Go before executing side effects.
  • 4. Make Every Turn Durable (Temporal v1.50): With googleadk + workflowstreams, worker crashes and browser refreshes become non-events.
