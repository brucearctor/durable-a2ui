Act I · The Problem

The "90% Agent Demo Trap"

1. Fragile Memory

In-Process State Dies

Standard agent loops store conversation history, cart state, and tool results in RAM. One container deploy or OOM kill wipes the entire session.

2. Text-Only Walls

Markdown Is Not an App

Streaming raw markdown forces users to read walls of text instead of interacting with structured cards, progress bars, and approval buttons.

3. Siloed Agents

Bespoke REST Glue

Without a standard wire protocol, every specialist agent speaks a custom JSON format—and a single timeout breaks the entire multi-agent chain.

💡 The Core Thesis

ADK gives your agent a brain. A2A gives it colleagues. A2UI gives it a face. Temporal gives it a spine.

Act II · Agent-to-UI (A2UI v1.0)

Declarative Surfaces + Durable Streams

// 1. Send structure ONCE when workflow starts
ui.Publish(a2ui.CreateSurface("order-tracking"))
ui.Publish(a2ui.UpdateComponents("order-tracking", []any{
  a2ui.Column("root", []string{"header", "progress", "actions"}),
  a2ui.Text("header", a2ui.Path("/stageTitle"), "h2"),
}))

// 2. Push lightweight JSON Pointer deltas per stage
ui.Publish(a2ui.UpdateDataModel("order-tracking", map[string]any{
  "stage":      "preparing",
  "stageTitle": "👨‍🍳 Preparing Your Order",
  "progress":   50,
}))

🌊 How workflowstreams Works

  • Durable Topic Log: Every ui.Publish(msg) is recorded deterministically in the Temporal workflow execution.
  • Zero-Loss Reconnect: Browser SSE passes Last-Event-ID; sc.Subscribe(ctx, FromOffset) resumes from the exact offset.
  • Late-Joining Devices: Scan the QR code halfway through an order—your phone replays messages #0..#N in milliseconds and renders the live surface.
  • Bidirectional Signals: Clicking an A2UI Button posts a Temporal Signal right back into workflow.Selector.

Inside go.temporal.io/sdk/contrib/googleadk

// 1. Bridge Temporal's deterministic clock, RNG & coroutines into ADK
adkCtx := googleadk.NewContext(ctx)

// 2. Deterministic in-workflow tool (zero Activity overhead!)
manageCartTool, _ := functiontool.New(functiontool.Config{
  Name: "manage_cart",
}, func(tctx tool.Context, args ManageCartArgs) (map[string]any, error) {
  // Directly mutates workflow local state on workflow coroutine
  *cart = append(*cart, item)
  return map[string]any{"cart": *cart}, nil
})

// 3. External I/O wrapped as a durable Temporal Activity
findSpotsTool, _ := googleadk.ActivityAsTool(
  A2AFindRestaurants,
  workflow.ActivityOptions{StartToCloseTimeout: 15 * time.Second},
)

⚡ Why This Architecture Wins

  • Deterministic Replay: Every Gemini LLM call runs through googleadk.InvokeModel Activity. On worker crash recovery, Temporal replays recorded LLM responses without re-billing tokens.
  • Zero-Hop State Tools: browse_catalog, manage_cart, confirm_order, and render_ui run in-workflow in microseconds.
  • Infinite Sessions: googleadk.ExportSession and ImportSession snapshot ADK memory across ContinueAsNew boundaries.

Safety & Governance

Prompt Instructions Are Not Guardrails

1️⃣ Programmatic Tool Guardrail

In pkg/concierge/agent.go, if the user mentions an allergy or vegan/gluten restriction, confirm_order checks !*dietaryChecked in Go code and blocks checkout until A2A :9002 verifies safety.

2️⃣ >\$100 Manager HITL Gate

When cart total exceeds \$100, the workflow pauses before charging and streams an interactive A2UI Manager Approval card (`approve` / `reject` signal).

3️⃣ Child Workflow Handoff

Once approved, ConciergeWorkflow spawns OrderWorkflow (`Tab 1`) as a Temporal Child Workflow and mirrors live delivery progress into chat!

Wrap-Up & Q&A

4 Rules for Production AI Agents in 2026

✅ Architectural Takeaways

  • 1. Separate Structure from State (A2UI v1.0): Send component trees once; stream lightweight @path JSON Pointer data-model deltas.
  • 2. Standardize Agent Boundaries (A2A): Discover specialist agents via /.well-known/agent-card.json and communicate over JSON-RPC 2.0.
  • 3. Enforce Guardrails in Code, Not Prompts: Check safety invariants and human approval gates deterministically in Go before executing side effects.
  • 4. Make Every Turn Durable (Temporal): With googleadk + workflowstreams, worker crashes and browser refreshes become non-events.
